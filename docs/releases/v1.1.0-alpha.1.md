# TizenHalo v1.1.0-alpha.1 — experimental compatibility tests

**Public test build. Compiled and checked offline; this revision has not yet been
validated on a TV.** The stable [v1.0.0](https://github.com/tenda96/TizenHalo/releases/tag/v1.0.0)
remains available for the Q74T reference setup.

This alpha adds complete `ppi_ve` / `ve` / `cs_ve` RGB-family discovery, RGB startup
independent of full-frame libraries, a separate experimental S84F full-frame
contract, profile-specific settings/methods and an evidence-based TV catalogue.
There is no universal Samsung/Tizen support claim and no new 30/60 capture-FPS claim.

| Download | Test scope |
|---|---|
| `TizenHalo-1.1.0-q74t-55.tpk` | Q74T / T-NKMDEUC-2743.0, Tizen 5.5 reference regression |
| `TizenHalo-1.1.0-rgb-55.tpk` | Experimental RGB-only path, minimum API 5.5; actual runtime/device compatibility unverified |
| `TizenHalo-1.1.0-s84f-90.tpk` | Experimental QN77S84FAEXZA / Tizen 9 full-frame adapter, main-only, up to 960×540 |
| `TizenHalo-Compatibility-Probe-0.1.0-tizen50.tpk` | Separate read-only diagnostic for Tizen 5.0+, including the pending RU7100 investigation; no Ambilight output |

Use your normal Apps2Samsung/per-TV signing process. Install one app profile at a
time; they share application IDs. No TV firmware modification is required.
The Tizen numeric package version is 1.1.0; runtime logs show `tizenhalo-1.1.0-alpha.1`.

Please read the included **TESTING.md**, run one short identified SDR-video test
and report the exact model, firmware, installed Tizen version, asset name and result.
Attach `/api/status` or the diagnostic report, masking personal network details.
Report install/menu/service failures too. Do not post certificates or native libraries.

RGB spot refresh, full-frame capture and interpolated LED output are different
measurements. No model is promoted to supported solely because an upstream project
works or the offline tests pass. RU7100/Tizen 5.0 and Q80A/Tizen 6 full-app support
remain research.

Offline validation: three builds, matching manifests/runtime targets/profiles,
25 signed-file digest checks per app package, native header/bounds checks,
settings/layout migration, profile restrictions, UDP interpolation and layout-editor
regressions. The restricted RGB-5.5 and Q74T-5.5 artifacts share the same app DLL.

The optional test-kit ZIP contains these assets, instructions, source metadata and
SHA256SUMS. Full instructions and the device catalogue are also in the tagged source.
